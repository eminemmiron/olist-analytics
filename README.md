# Операционная аналитика e-commerce платформы Olist

## О проекте
Аналитический проект на основе реальных данных бразильского маркетплейса Olist (2016–2018).  
Цель — выявить узкие места в бизнесе и дать рекомендации по доставке, удержанию клиентов и качеству продавцов.

## Датасет
[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) — 100k заказов, 9 таблиц, период 2016–2018.

## Ключевые инсайты

### Доставка
- Средний реальный срок доставки — **12 дней** против обещанных **23 дней**
- Платформа намеренно занижает ожидания: заказы приходят в среднем на 11 дней раньше срока
- Только **7.4% заказов** опаздывают
- Корреляция задержки и оценки покупателя: **−0.23**

### Клиенты (RFM)
- **67% клиентской базы** — неактивные сегменты (потерянные, спящие, под угрозой)
- Сегмент Чемпионов (4% базы) даёт средний чек **353 BRL** — в 2 раза выше остальных
- Большинство покупателей совершают только **1 заказ** — платформе не хватает механизмов удержания

### Продавцы
- **15.7% продавцов** имеют долю негативных отзывов выше 30%
- Корреляция между выручкой и качеством продавца: **−0.05** — проблемные продавцы продолжают продавать без санкций
- Средняя оценка платформы: **4.15 / 5**

### Сезонность
- Пик продаж — **май** (День матери в Бразилии)
- Активность покупателей в будни на **30% выше** чем в выходные
- Категория `health_beauty` резко растёт в Q2 — подарочный сезон

## Рекомендации
1. **Удержание клиентов** — внедрить программу лояльности, скидку на второй заказ для новых покупателей
2. **Контроль продавцов** — отключать продавцов со средней оценкой ниже 3.0 более 60 дней подряд
3. **Сезонные кампании** — усиливать рекламу в апреле перед майским пиком, таргетировать будни
4. **VIP-сегмент** — запустить отдельную программу для Чемпионов (4% базы, чек x2)
